How the 2D System Works

  • 12 Segments (around): The SKILL type - what capability you have
  • 5 Rings (in→out): The ROLE type - how you apply the skill
  • Each cell = A specific Skill × Role combination (e.g., "Analyzing as a Guide" = Analytics Coach)
  • Multiple cells can light up - Most people have 2-4 primary combinations
  • AI infers from language: "I teach people about data" → Analyzing × Guide
  • User confirms after clustering to ensure accuracy
