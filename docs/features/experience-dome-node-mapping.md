# Experience Dome — Node Mapping

Maps every Rule Break Tree node to its "experience it unlocked" label.
Nodes marked PRUNE are infrastructure/industry innovations that don't translate to a personal experience someone could rate with an NS state.

**NS Rating**: Vibe Rise / Fun / Pressure / Uninterested
**Dome Logic**: Vibe Rise + Fun = lit (safe dome). Pressure = growth edge. Uninterested = auto-remove. No data = dark/unexplored.

4. **Threat and Fire are thinnest** — many nodes are infrastructure/military, not personal experience
5. **~330 keep nodes is a lot** — need a "core" layer (~80 nodes, one per sub-branch) and an "expanded" layer (all ~330)

### Overlay architecture
1. **Innovation Layer** (current) — all 486 historical nodes + 22 predictions, educational timeline
2. **Experience Layer** — ~330 experiential nodes, personal dome visualization
3. **Core Experience Layer** — ~80 nodes (one representative per sub-branch), simplified for quick rating
4. **My Data Layer** — user's NS ratings + quest/courage data overlaid on either experience layer

### Data source for populating the dome
- `quests.branch` — already classifies quests into the 12 primals (code handles both text and text[], normalizes to array)
- `quest_completions` — NS state on each courage challenge completion
- `nervous_system_checkins` — daily NS check-ins
- `life_path_sessions` — career NS ratings
- Direct rating — user taps a node and rates it (same 4-state: Vibe Rise / Fun / Pressure / Uninterested)

### "Collect dots" connection
Each lit node = a collected dot. The dome visualization IS the dot collection map. Convergence (where two lit branches have a merge line) = connected dots. Personal monopoly = the unique shape of your dome.
