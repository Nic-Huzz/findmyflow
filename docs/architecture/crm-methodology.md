## Overview

### The Purpose

> Make all sales and marketing activities as easy as possible.

The CRM does this by:
1. **Generating tasks** — What to do
2. **Generating content/answers** — How to do it
3. **Tracking everything** — Easy to manage + review performance

### The Unique Advantage

Most CRMs start from scratch. Users enter basic business info and get generic outputs.

**FindMyFlow CRM inherits everything from the Business Tab:**
- Skills, problems, persona
- Offer stack, pricing, positioning
- Validation data, testimonials
- Patterns, edges, 3% history

This makes the AI more intelligent than any other CRM.

### The Core Insight

> "AI is great at the middle" — Balaji

The whole app creates this flow:

```
START                    MIDDLE                      END
(Question Flows)         (AI Intelligence)           (Outputs to Use)
     │                        │                           │
     ▼                        ▼                           ▼
Capture structured      AI processes with          Higher quality
information             rich context               than generic AI
```

## Tower Structure

The CRM is organized into three towers:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           CRM TOWERS                                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│    ATTRACT               NURTURE                TOOLS                    │
│    ───────               ───────                ─────                    │
│    Build audience        Build relationships    Track + optimize         │
│                                                                          │
│    • Content Create      • Contacts             • Analytics              │
│    • Content Queue       • Email Sequences      • Performance            │
│    • Content History     • Sales Pipeline       • Calculators            │
│    • Marketing           • Warm Outreach        • Scripts                │
│    • Pages               • Deal Management      • Execute                │
│    • Cold Outreach                              • Reports                │
│                                                                          │
│    ════════════════════════════════════════════════════════════════     │
│                                                                          │
│    User Flow:                                                            │
│                                                                          │
│    ATTRACT ──────► NURTURE ──────► CONVERT ──────► (repeat)             │
│    (content)       (relationship)  (sale)                                │
│       │                │               │                                 │
│       └────────────────┴───────────────┴─────────► TOOLS (track all)    │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### Tower Details

**ATTRACT Tower** — Getting attention
- Content generation + scheduling
- Marketing campaigns
- Landing pages
- Outreach (cold + warm)

**NURTURE Tower** — Building relationships
- Contact management
- Email sequences
- Sales pipeline
- Lead scoring (PTUF)
- Follow-up tracking

**TOOLS Tower** — Tracking + optimizing
- Analytics dashboard
- Performance reports
- Calculators (LTV, CAC, PTUF)
- Sales scripts
- Execute (daily priorities)

## Open Questions

### Architecture Questions

1. **Context display** — Should we show users explicitly what the AI knows about them? ("Your content is personalized because...")

2. **Partial context** — Can CRM work if Business Tab is incomplete? Or require minimum completion?

3. **Context refresh** — When Business Tab data changes, how quickly does CRM reflect it?

4. **Feedback loops** — When CRM content performs well/poorly, does that feed back into Business Tab insights?

### UX Questions

1. **Task prioritization** — How does AI decide what's most important today?

2. **Content approval** — One-click post, or always require review?

3. **Override patterns** — If user wants to do something their pattern says is scary, encourage or warn?

4. **Onboarding** — New CRM users need to understand the inherited context advantage

### Integration Questions

1. **Healing → CRM** — Should pattern awareness affect CRM task generation? (e.g., don't suggest "go live" if visibility pattern is active)

2. **3% in CRM** — Does CRM have its own 3% reflection, or inherit from Business Tab?

3. **Weekly Planning** — Does CRM weekly planning replace or complement Business Tab planning?
