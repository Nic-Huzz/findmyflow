Implementation Notes

  • Data sources: All from existing tables. experience_attendees.attended, experiences.total_revenue, experiences.three_percent_note. Repeat count = cross-experience join.
  • "vs last" comparisons: Query previous experience via previous_experience_id FK. If null (first event), show "1st event" badge instead.
  • Repeat attendees: SELECT contact_id, COUNT(*) FROM experience_attendees WHERE user_id = X AND attended = true GROUP BY contact_id HAVING COUNT(*) > 1
  • Revenue per person: total_revenue / attended_count
  • "Run It Again" button: Already exists in ExperienceCreate as "Run Again" flow with pre-filled data.
  • Show condition: Only appears after attendance + revenue are both logged. Before that, Post tab shows the input tools (AttendanceMarker, RevenueLogger).
  • First event: No "vs last" data. Change badges show "1st event" in neutral gray. Repeat section shows "No repeat attendees yet. Run another event to see who comes back."
