**Created**: 2026-11-14
**Status**: Phase 0 (Validation)
**Source of truth**: Obsidian `Business/Intergenerational Flow Model.md`

## The Pivot

Find My Flow is moving to an intergenerational model:
- **50+ year olds** (post-corporate, seeking life fuels) pay for retreats + monthly guru stack subscription
- **20-30 year olds** get the same pipeline free/subsidised, funded by the 50+ segment
- **Creator OS** repositions to headset-sales ecommerce (premium positioning)
- **Guru Stack** (`/creations/guru-stack`) is both a standalone product AND the engine inside this pipeline
- **Pipeline**: Experience Game → Category Pirates → Guru Stack assets → Launch Support

## Phase 0: Validate the Premise (Weeks 1-4)

**Goal**: Before building anything, test the riskiest assumptions with 5-8 conversations (dad, mum, Karen Wong, friends of their vintage).

### Hypotheses

| # | Hypothesis | How to Test | Kill Signal |
|---|-----------|------------|-------------|
| H1 | 50+ post-corporate people feel the "missing life fuels" pain | Run the Four Channels of Aliveness diagnostic in conversation. Ask which channels are starved. Record their language. | 3/5 don't recognise the pain or frame it completely differently |
| H2 | They want to DO something about it (not just therapy/retreat-tourism) | After naming the pain: "If you could spend the next 6 months doing something that lit up those channels, what would it be?" Note: "doing" not "building" — some want a hobby, not a business. | Most want passive consumption (retreats, courses), not active engagement of any kind |
| H2b | The split between Play (hobby) and Build (commercial) is roughly even | After H2, ask: "Would you want to turn this into something others can experience/buy, or is this purely for you?" Track the ratio. | If 90%+ are one track, the two-track model may be unnecessary |
| H3 | For Track B people: "AI builds it for you" resonates more than "learn to build it yourself" | Describe both options to those who want to go commercial. Which excites them? | Consistently prefer self-serve learning over done-for-you |
| H4 | Retreat-as-onboarding is the right entry point | "Would you pay $X for a 3-5 day retreat that includes wellness + discovery + community?" Test price anchors. | Price resistance is about format ("I don't have 5 days"), not price |
| H5 | The cross-generational matching appeals to both sides | Ask 50+: "Would you pay for a 20-something to execute your digital presence 2-3 days/week?" Ask 20-30s: "Would you do 2-3 days/week work for someone else's project in exchange for living expenses + free time?" | Either side consistently says no |

### Deliverable
- 5-8 voice note conversations summarised into a validation doc
- Life Fuels diagnostic results for each person
- Language capture (what words do THEY use for this pain?)

## Phase 1: Prototype with Dad (Weeks 4-8)

**Goal**: Run ONE person through the full pipeline manually. Dad is the perfect first test.

### Steps
1. **Experience Game** (existing) — run him through it. Note all UX friction for 50+ (font sizes, language, pacing, steps that confuse)
2. **Life Fuels diagnostic** — which channels are starved? Use `/try/aliveness` quiz
3. **Category Pirates discovery** — run the CP Quick-Start (FROTO, Supers, Violence). What category emerges?
4. **Guru Stack asset creation** — use the guru stack MCP to create his landing page, positioning, basic content
5. **Support model test** — does he want to operate Claude himself, or does he need a human helper?

### Hypotheses

| # | Hypothesis | What to Watch |
|---|-----------|--------------|
| H6 | Experience Game works for 50+ with minimal modification | UI comprehension, time to complete, quality of dome results |
| H7 | CP process produces a meaningful "category" for non-entrepreneurs | Does the output feel like direction or forced? Does it help with positioning and messaging even if they're not building a business? |
| H8 | Guru Stack can create assets for someone with zero tech/marketing literacy | Quality of output, iterations needed, does it feel "theirs"? |
| H9 | Monthly cadence keeps momentum | Does dad engage week-over-week or does interest drop after initial setup? |

### Deliverable
- Dad's full pipeline results documented
- UX friction log for 50+ audience
- "What worked / what didn't" honest assessment
- Decision: proceed to retreat or iterate pipeline first?

## Phase 2: First Retreat Test (Weeks 8-16)

**Goal**: Run a small retreat (6-8 people) using the blueprint validated in Phase 1.

### Retreat Design
- **Format**: 2-3 days (not 5 — test shorter first to reduce barrier)
- **Content**: Shift Architecture healing experiences + Experience Game + Life Fuels diagnostic + CP discovery + community formation
- **Modalities**: Breathwork, shaking, Healing Compass, guided wellness (reframe existing Shift Architecture for post-corporate audience)
- **Community**: Designed for bonding — shared meals, vulnerability exercises, peer support

### Hypotheses

| # | Hypothesis | What to Watch |
|---|-----------|--------------|
| H10 | Retreat creates sufficient "glue" that attendees stay on monthly subscription | Month 1 retention. Month 2 retention. Do they message each other outside the retreat? |
| H11 | 6-8 strangers in this demographic bond through the process | Organic connection during retreat. WhatsApp group activity post-retreat. |
| H12 | At least 2/8 want to continue into active project building | Not everyone will want to build something. That's fine. But if zero do, the model breaks. |
| H13 | The price point works | Test: flat retreat rate + $X/mo ongoing. What does this group accept? |

### Deliverable
- Retreat facilitation guide (adapted Shift Architecture)
- Post-retreat retention data
- Price sensitivity data
- Community formation assessment
- Decision: proceed to cross-generational bridge or iterate retreat?

## Phase 3: Test the Bridge (Weeks 16-24)

**Goal**: Attempt the first 50+ ↔ 20-30 match. Only after Phase 2 proves the 50+ side works.

### Hypotheses

| # | Hypothesis | What to Watch |
|---|-----------|--------------|
| H14 | A 20-30 year old can execute guru stack outputs for a 50+ person with minimal supervision | Quality of work, communication friction, autonomy level |
| H15 | The work exchange model produces satisfaction on both sides (not resentment) | Check in separately with both parties at week 2, 4, 8 |
| H16 | The 20-30 year old's own flow journey benefits from the structure | Are they using their free days productively? Is the exposure to the 50+'s project educational? |
| H17 | The cultural thesis holds — does knowing a 50+ person is also "doing this" shift perception? | Language from both sides. Do 20-30s reference the 50+ as proof? Do 50+ reference the 20-30s? |

### Deliverable
- Match documentation (how it was set up, what happened)
- Satisfaction scores from both sides
- Iteration recommendations for the matching model
- Decision: scale or redesign?

## Strategic Architecture Decision (Deferred)

Testing before committing. Three possible architectures:

| Option | Description | When to choose |
|--------|------------|----------------|
| **A) Fork** | Two app modes (like consumer/creator today). 50+ simplified, retreat-led. 20-30 current app. | If 50+ need fundamentally different UX |
| **B) Layer** | 50+ journey is premium layer ON TOP of existing app. Same core, different entry + support. | If most features translate with minor tweaks |
| **C) New product** | Intergenerational model is a new brand (e.g. "Flow Collective") using FMF components | If the audiences are too different for one brand |

Decision point: end of Phase 1, after running dad through the pipeline.
