# CrossFit Success Model — What Vibe Rise Can Copy

## The Formula
```
Ancient practice + modern community + daily shareable ordeal + identity language + distributed facilitation + polarising positioning = Phase 3 at scale
```

## The 7 Conditions

| # | Condition | CrossFit | Vibe Rise | Gap |
|---|-----------|----------|-----------|-----|
| 1 | Founder's wound | Glassman vs conventional training | Huzz VC burnout → healing | Ready |
| 2 | Secular reframe | "Functional fitness" (performance) | "NS regulation" — needs sharper language | Needs work |
| 3 | Shareable ordeal | WOD (named, timed, comparable) | Wahoo system | Partial — not yet as shareable |
| 4 | Franchise model | $3K/year affiliate, 15K boxes | Headset rental + certification | Early |
| 5 | Self-policing community | Box culture, peer accountability | Fantasy League | Early |
| 6 | Polarising positioning | "Forging elite fitness" | "Safety problem, not inspiration problem" | Ready, not deployed |
| 7 | Hero story in product | Ring bell, write time on board | Identity celebrations, review card | Partial |

## Biggest Gap: The Named Daily Shareable Ordeal
Make the Wahoo as named, specific, shareable, and comparable as a WOD.
"I did my first Vulnerable Wahoo" = "I did Fran in 4:32"

## What CrossFit Got Wrong (Avoid)
1. Injury culture → Safety as Mechanism is the antidote
2. Founder as liability → build brand bigger than Huzz
3. No progression → 9 levels solve this
4. Intimidation barrier → 7-day challenge solves this
