The Key Insight: Matrix Codes ARE the Operating System from Each Stage

The 5 matrix codes aren't random limiting beliefs. They map directly to where they were installed:
Deepest → Shallowest (Installation Order)
1. Emotions = Unsafe ← Stage 1-2 (earliest)
2. Success = Status ← Stage 2-3
3. Safety = Sameness ← Stage 3-3.5
4. Visibility = Risk ← Stage 3-3.5
5. Worth = Productivity ← Stage 3-4 (shallowest)
The Onboarding Connection
When a user picks an extreme zone at a stage, they've revealed a wound. The matrix code that lives at that stage is likely active.

So after picking a zone, we don't ask "which archetype?"
We ask: "Which of these feels most true for you?" — showing the 1-2 matrix codes that map to that stage. This connects their story choice to the specific belief that was installed there.

Proposed Onboarding: Stage → Zone → Matrix Code → Archetype

For each stage:
  1. Show the story + 3 AI scenes with user's face
  2. User picks a zone (top left / diagonal / bottom right)
  3. IF they pick an extreme (not diagonal):
     → Show the matrix code(s) mapped to that stage
     → "Does this feel true?" (yes/no per code)
     → The archetype is ALREADY determined by the zone:
        Top left = Performer/Controller (Sympathetic)
        Bottom right = Perfectionist/Ghost (Dorsal)
  4. IF diagonal: "This one didn't get you. Nice." → move to next stage

Result: A map of stages → zones → active codes → dominant archetype
The archetype emerges from the PATTERN of choices, not from a quiz.

What This Replaces

Currently: Matrix Codes is a standalone deep dive quiz. User picks 3 fears from a list of 5, answers behavior questions, gets archetype reveal.

With this: The matrix codes become embedded IN the onboarding story. Each code surfaces naturally at the stage where it was installed. The archetype isn't quizzed — it's revealed by the pattern of choices across all 6 stages. Much more powerful because the user lived through the story before seeing the result.
